# RQ2 figure captions

These figures are diagnostic-only when generated with `rq2_mini.yaml`.

- **Fig_RQ2_risk_coverage.** Detection error risk as progressively more uncertain detections are retained. Lower curves are better.
- **Fig_RQ2_validation_complementarity.** Train-normalized fixed deterministic and stochastic scores on validation detections; this plot is descriptive and does not select a test-time feature direction.
- **Fig_RQ2_reliability.** Calibrated predicted error probability against observed error frequency.
